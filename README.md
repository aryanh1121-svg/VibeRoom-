# VibeRoom Free Starter

Mobile-first React/Vite starter for VibeRoom.

Included:
- Home / Explore / Message / Me
- Live room UI
- Virtual VibeCoins (local demo)
- Virtual gifts
- Social games button
- PK-ready room UI
- Owner management center
- Manager/Official role demo
- Ban/unban demo
- Firebase-ready architecture placeholder

Important:
This is a frontend/demo starter. Real voice, Firebase authentication, Firestore security rules,
server-issued voice tokens, and production moderation must be connected before public launch.
Coins are virtual demo currency only; no gambling, betting, or cash-out is included.

Run:
npm install
npm run dev
